# P2.3 双语论文、知识图谱与统一日历 PRD

版本：0.6.0  
日期：2026-08-01

## 目标

把论文、导师、研究方向、机构和机会连接成可检索的学术情报网络，并把所有明确截止日期、开放日期和个人准备动作放入同一日历。页面同时适配电脑和手机。

## 用户问题

- 英文论文标题和摘要阅读成本高，无法快速判断相关性。
- 论文、导师、研究方向和招生/岗位机会分散，关系不直观。
- 北京高校、全国重点实验室与中科院研究所缺少统一入口。
- “截止日期”混合了官方日期、经验估计、滚动申请和未知状态，容易造成误判。

## 功能需求

### F1 双语论文

- 保留原始英文标题与摘要，新增中文译文。
- 使用 Cloudflare Workers AI 原生绑定异步翻译；翻译结果写入 D1，页面不重复实时调用模型。
- 每次 Cron 最多翻译 6 篇，失败记录错误并在后续运行重试。
- 无摘要时明确显示“来源未提供摘要”，不得生成不存在的内容。

### F2 知识图谱

- 节点：论文、导师、研究方向、机构、机会。
- 关系：作者、研究方向、任职机构、机构发布机会。
- 只展示数据库中有证据的关系，不用模型猜测隐含关联。
- 支持类型筛选、点击查看详情和无 Canvas 的可访问列表。

### F3 北京科研生态

- 首批覆盖北大、清华、北师大、北理工、首都医科大学、中科院心理所、中科院生物物理所、中科院自动化所及相关重点实验室。
- 收录博士、科研助理、研究助理、实习和研究岗位。
- 每条机构、导师与机会尽量关联官方入口；当前页面明确标注为高相关首批覆盖，不宣称穷尽北京全部机构。

### F4 时间表与日历

- 结构化保存 `opens_at`、`deadline_at`、时区和日期可信状态。
- 状态必须区分：`confirmed` 官方确认、`estimated` 预计、`rolling` 滚动、`unknown` 待确认、`closed` 已关闭。
- 对有日期的机会自动生成截止前 30、14、7、3 天及当天任务。
- 日历同时显示开放日、截止日和准备任务；滚动及未知日期单独列出，不伪造日期。
- 所有申请仍以官方页面及其时区为准。

## 非功能需求

- D1 迁移可从空库顺序执行；所有写入幂等。
- API 不缓存截止日期结果；页面失败时给出明确错误状态。
- Worker 使用结构化日志记录翻译数量、失败和完成时间，不记录完整敏感材料。
- TypeScript、ESLint、构建、单元测试和 SSR 测试全部通过。

## 验收标准

- `/papers` 同时显示中英文标题和摘要状态。
- `/knowledge-graph` 能浏览五类节点和事实关系。
- `/beijing` 能按机构类型和机会类型查看首批清单。
- `/calendar` 能按月/日查看任务，并能区分确认、预计、滚动和待确认日期。
- Cron 同一轮完成论文采集后执行有界翻译；翻译失败不影响职业来源巡检。
