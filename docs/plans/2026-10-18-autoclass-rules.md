# PRD-061/T1：自动归类规则设计

> 对应 trend issue #272。PRD：`adopted/PRD-061-brain27-auto-organize.md`。
> 下一步：T1 确认后进 T2（跨来源模糊去重，trend #275）。

## 一、定位

PRD-017 的 Wiki 是"图书馆"（负责"存"），PRD-061 是"图书管理员"（负责"自动整理"）。
T1 就是给管理员写《图书分类法》：先定下来分几类、每类怎么认、拿不准的怎么办。

**非目标**（PRD 要求，本设计遵守）：

- 不动 PRD-017 的条目 schema（WikiEntry 本体不加字段）。
- 不动人工确认闸门：归类/去重/关联的结果同样走人工确认才能入库
 （`requireHumanConfirm=true`，见 `lib/wiki/pipeline-config.ts`）。
- 第一期不用 LLM 做归类（规则 + 关键词 + 指纹，确定性优先；LLM 仅可做候选建议）。

## 二、三层分类体系

### L1 机构类型（新轴）

四类：`高校 / 研究所 / 企业 / 政府项目`。

- 与现有 `region`（地理维度）正交，不冲突：一个条目可以同时是"高校"+"英国"。
- 判定：机构白名单 + 关键词。
  - 白名单：`{机构名变体 → L1}`，如 `UCL / 伦敦大学学院 / University College London → 高校`。
    这张表同时是 T2 机构名归一化的前置资产，T2 直接复用。
  - 关键词：`大学 / University / 学院 → 高校`；`研究所 / 研究院 / Lab / 实验室 → 研究所`；
    `公司 / Inc / Ltd / 有限公司 → 企业`；`基金委 / 科技部 / 重点研发 → 政府项目`。
- 兜底：无法判定 → `L1=null`（不硬编），置信度扣分（见 §四）。

### L2 机会类型（复用现有枚举 —— T1 评审意见 1）

**直接采用 `WIKI_OPPORTUNITY_TYPES`**（`lib/wiki/schema.ts`，PRD-018 已在用）：

`phd / joint_phd / ra / campus / intern / research`

- 明确拒绝 PRD 初稿里的第二套说法（博士/博士后/教职/访问学者/奖学金）：
  同一维度两套词，检索、过滤、统计迟早对不上。
- 关键词映射（初版，后续随词典迭代）：
  - `博士 / PhD / doctoral → phd`（排除"联培/联合培养"）
  - `联培 / 联合培养 / joint → joint_phd`
  - `助理 / RA / research assistant → ra`
  - `校招 / 校园招聘 / campus → campus`
  - `实习 / intern → intern`
  - `访问学者 / visiting → research`（暂归 research，见下）
- 拟议枚举扩展（**非本 T1 范围**，留给 PRD-018 的枚举治理另提案）：
  `postdoc`（博士后）、`faculty`（教职）。理由：L2 现有枚举无处安放这两类；
  扩展需同步改 `WIKI_OPPORTUNITY_TYPES`、校验器、MCP schema、回归测试——单独立项，
  不在本设计内实施。

### L3 领域标签（T1 评审意见 2）

- **起点：`WIKI_DIRECTIONS` v0.1（`lib/mcp/tools.ts`，10 词），逐字复用**：
  `脑机接口 / 认知神经科学 / 脑成像 / 计算神经科学 / 神经调控 / 脑疾病 / 类脑智能 / 神经影像 / fMRI / EEG`
- 扩展方法（冷启动缓解，PRD 风险项的对策）：
  1. 从现有 Wiki 条目的 `facets.keywords` 做词频统计，Top 候选人工过一遍后并入；
  2. 与 L2 映射表交叉检查，已有映射的不重复造词；
  3. 每次扩展记 changelog（词、来源、日期），T5 验收时可审计。
- L3 可多选（数组）；L1/L2 单选。

## 三、关键词词典

结构（三张表，可落为一个 JSON/YAML 配置）：

```yaml
l1_dict:   # 词 → L1
  - { term: "大学",        value: "高校",   weight: 1.0 }
  - { term: "University",  value: "高校",   weight: 1.0 }
l2_dict:   # 词 → L2（值域 = WIKI_OPPORTUNITY_TYPES）
  - { term: "联培",        value: "joint_phd", weight: 1.0 }
l3_dict:   # 词 → L3（值域 = L3 词表）
  - { term: "脑机接口",    value: "脑机接口", weight: 1.0 }
org_allowlist:  # 机构名变体 → L1（T2 复用）
  - { names: ["UCL", "伦敦大学学院", "University College London"], value: "高校" }
```

匹配规则：

- 输入文本 = `title + \n + body + \n + source`，分词复用 `lib/wiki/rag.ts` 的 `tokenize`
 （中文 bigram + 英文词切分，与检索层同一套切分口径）。
- 每层独立计分；命中多条时取置信度最高者（L3 允许多命中：得分过阈的全收）。
- 机构白名单优先于关键词（白名单命中直接定 L1，不参与权重竞争）。

## 四、置信度计算与闸门

计分（每层 0~1）：

- 每层得分 = 命中词权重和 / 该层满分（满分 = 该层词典在文本中理论最大命中权重，取 1.0 归一）。
- 综合置信度 = `0.3 × L1 + 0.3 × L2 + 0.4 × L3`（L3 信息量最大，权重最高）。
- 惩罚项：L1 未判定 `-0.1`；标题零命中 `-0.2`；低可信来源 `-0.1`。下限 0。

闸门（两档，都在人工确认总闸门之内）：

| 综合置信度 | 去向 |
|---|---|
| `≥ 0.7` | 归类结果自动附着，走正常待确认流（人工批量确认） |
| `< 0.7` | 进"低置信待确认"，标记 `needsReview=true`，人工必须逐条核对分类后才放行 |

关键纪律：**闸门只决定"人工看多细"，不决定"是否入库"**——入库永远要人工确认
（PRD-017 `requireHumanConfirm`）。`<0.7` 的含义是"机器拿不准"，不是"机器拒绝"。

每条归类结果附带解释字段（人工确认时可见，可审计）：

```json
{ "l1": "高校", "l2": "phd", "l3": ["脑机接口"],
  "scores": { "l1": 1.0, "l2": 0.85, "l3": 0.9 }, "confidence": 0.91,
  "hits": ["University", "PhD", "脑机接口"], "needsReview": false }
```

## 五、导师/PI 字段预留（T1 评审意见 3）

- 现状：`WikiEntry` / `McpOpportunity` 均无导师字段，T3 的"同导师"关联无字段可用。
- 本 T1 设计（**不动 schema，只定规范**，故本 PR 纯文档）：
  新增可选字段 `mentor?: string[]`（导师/PI 姓名数组），拟放在 `McpOpportunity`
  扩展层（与 `org / deadline / funding_note` 同层），不进 `WikiEntry` 本体。
- 提取规则 v0.1：从 title/body 匹配 `导师|PI|教授 + 人名` 模式；多导师取数组；
  提取不到 → 空数组（不编造）。
- T3 消费：同导师关联 = `mentor` 数组交集非空。T2 不消费该字段。

## 六、与 T2 / T3 / T4 / T5 的衔接

- **T2 跨来源模糊去重**（trend #275）：在 PRD-017/T4（`lib/wiki/maintenance.ts`
  的 `dedupeKey`/`dedupeEntries` 精确去重）之上加模糊层——机构名归一化
  （复用 §三 机构白名单）、标题相似度（token 交集/Jaccard > 阈值，阈值从 0.8 起保守）、
  合并后 `source` 变数组保留多源证据链；合并结果走人工确认（可拆分回滚）。
- **T3 历史关联**（trend #277）：新条目生成时跑三路——同机构（L1+机构名）、
  同领域（L3）、同导师（§五 mentor 交集）；以"相关条目"区块挂载，不改历史条目。
- **T4 增量流水线**（trend #279）：位置 = 日报 → PRD-017 起草 → 本 PRD 归类/去重/关联
  → 待确认区 → 人工确认入库；只处理当日新增/变更，全量回算只在规则版本升级时手动触发。
- **T5 验收**（trend #281）：归类准确率 ≥90%（测试集；T1 词典冷启动质量由 T5 卡线）、
  去重召回率、关联覆盖率；增量运行不重算全库；不破坏 PRD-017 闸门。

## 七、不确定项

1. L1 四类是否够用（"政府项目"与"企业"边界，如企业联合实验室）→ T5 看误分类分布再定。
2. 0.7 闸门与 0.3/0.3/0.4 权重是初值，上线后按人工确认的纠正率调。
3. `postdoc` / `faculty` 枚举扩展提案另起，不在本 PRD 内。
4. 机构白名单冷启动：先从现有 D1 sources 表反推 Top 机构，人工过一遍。
