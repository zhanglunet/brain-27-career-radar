# PRD-337/T1 设计：跨平台公开信息聚合

> trend issue #1616 · 借鉴 sherlock-project/sherlock（MIT，实测）

## 目标

求职目标人 / 公司的公开信息一键聚合，仅公开来源，每条注明来源与时间。

## 方案要点

- 仅公开来源：登录态/付费源一律不接
- 每条注明来源与时间（可追溯）
- 聚合结果只做参考素材，不自动生成投递材料

## 任务拆分

1. T1（本层）：设计文档与验收口径；
2. T2：最小实现（有测试）；
3. T3：闸门/深化（有测试）；
4. T4：划界断言（有测试）；
5. T5：验收试运行（全链跑通）。

## 红线

- 文档与示例零真实主机名/IP/账号/密钥。
- 各仓既有红线继续生效。
