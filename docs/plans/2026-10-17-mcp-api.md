# PRD-018/T1 草稿：brain-27 只读 MCP —— 接口设计 v0.1

> 对应 trend issue #71。下一步：T1 确认后进 T2/T3（tools 实现）。

## 一、设计原则

- **只读**：scope 固定为 `opportunities:read` + `calendar:read`，无任何写入 tool。
- 每个返回结果带 `last_verified`（数据新鲜度），调用方自己判断。
- 资助类型枚举与网站一致，不发明新词。

## 二、Tool 1：search_opportunities

**输入 schema**：

```json
{
  "type": "object",
  "properties": {
    "direction":   { "type": "string", "description": "研究方向关键词，如 脑机接口 / 认知神经科学 / 脑成像" },
    "region":      { "type": "string", "enum": ["英国", "中国大陆", "中国香港", "爱尔兰", "全球"] },
    "type":        { "type": "string", "enum": ["phd", "joint_phd", "ra", "campus", "intern", "research"] },
    "funding":     { "type": "string", "enum": ["full", "partial", "mixed", "self", "tbd"] },
    "limit":       { "type": "integer", "default": 10, "maximum": 50 }
  }
}
```

**输出 schema**：

```json
{
  "type": "object",
  "properties": {
    "total":         { "type": "integer", "description": "符合条件的总数" },
    "opportunities": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "id":            { "type": "string" },
          "title":         { "type": "string" },
          "org":           { "type": "string" },
          "type":          { "type": "string" },
          "funding":       { "type": "string" },
          "funding_note":  { "type": "string", "description": "如国际学生学费差额风险提示" },
          "deadline":      { "type": "string", "description": "ISO 日期；滚动申请填 rolling；待确认填 tbd" },
          "deadline_kind": { "type": "string", "enum": ["fixed", "rolling", "tbd", "estimated"] },
          "evidence_url":  { "type": "string", "description": "官网原文链接" },
          "confidence":    { "type": "string", "enum": ["high", "medium", "low"] },
          "last_verified": { "type": "string" }
        }
      }
    }
  }
}
```

**示例调用**：`search_opportunities({direction: "脑机接口", type: "phd", limit: 5})`
→ 返回 5 条博士机会摘要，每条带截止日与官网链接。

## 三、Tool 2：upcoming_deadlines

**输入 schema**：

```json
{
  "type": "object",
  "properties": {
    "days":      { "type": "integer", "default": 30, "description": "未来 N 天内截止" },
    "direction": { "type": "string", "description": "可选，方向过滤" },
    "limit":     { "type": "integer", "default": 10, "maximum": 50 }
  }
}
```

**输出 schema**：

```json
{
  "type": "object",
  "properties": {
    "items": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "id":         { "type": "string" },
          "title":      { "type": "string" },
          "org":        { "type": "string" },
          "deadline":   { "type": "string" },
          "days_left":  { "type": "integer" },
          "evidence_url": { "type": "string" }
        }
      }
    },
    "by_month": {
      "type": "object",
      "description": "按月聚合计数，如 {\"2026-11\": 12, \"2026-12\": 8}",
      "additionalProperties": { "type": "integer" }
    }
  }
}
```

**排序规则**：`fixed` 截止按 `days_left` 升序；`rolling` 降权排后并标注；
`tbd`/`estimated` 单独分组，不混入"临近"排序。

## 四、错误码表

| code | 含义 | 处理 |
|------|------|------|
| 400 | 参数非法（如 region 不在枚举内） | 返回合法枚举值 |
| 404 | 无符合条件的结果 | 返回空数组 + total=0，不报错 |
| 429 | 触发限流 | 返回 retry_after 秒数 |
| 503 | 数据源暂不可用（D1 超时） | 返回 last_good 数据 + stale 标记（如有缓存） |

## 五、T2/T3 衔接

- T2 实现 `search_opportunities`：读 D1（或现有 API 层），资助映射表单独维护。
- T3 实现 `upcoming_deadlines`：统一日历数据接入，四类 deadline_kind 分开处理。
- T4 鉴权限流：匿名低频免费、高频需 token；结果缓存防 D1 被刷爆。
