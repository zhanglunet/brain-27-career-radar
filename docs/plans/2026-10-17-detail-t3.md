## 设计要点

- **找到**：返回全部字段（WikiEntry 本体 + MCP 扩展字段 org/funding_note/deadline/deadline_kind）
  + 证据链（source / source_url / d1_evidence）+ 解析后的截止日（deadline_kind/days_left，
  复用 `deadlines.ts` 的 `parseDeadline`，缺省时按字面推断）。
- **未找到**：返回 `{ found: false, id }`，不抛错——路由层映射为 404（接线示例见模块文末注释）。
- **历次核验记录**：当前可用字段只有 `created` / `last_verified` 两个时间点，
  如实声明；完整历史待 PRD-017/T5（trend #70）的 D1 适配层补齐，不编造。
- 缺失字段（org/funding_note/d1_evidence/deadline）按 null 处理，不崩。
