## T1 §四" T2 衔接"落实

- tags → 过滤面：`search(index, q, { facets: { type, region, funding } })` 精确匹配。
- confidence → 排序权重：high 1.0 / medium 0.7 / low 0.35；low 默认不进结果（`includeLowConfidence` 可打开）。
- status → 默认过滤：默认只返 `active`；`expired` 保留可追溯（`status: "expired"` 可查）；`merged` 是去重指针，不进检索。
- body + title → 向量化文本（`entryText`，另加方向关键词）。
- d1_evidence → 证据链：每条结果必带 `source / source_url / d1_evidence / last_verified`。

## 3 条 T1 review 意见落实

1. `verdictToConfidence`：confirmed→high，pending→medium，debunked/rumor→low。不再是"审核过 ⇒ high"。
2. 枚举复用 PRD-018：region/type/funding 与 PR #17 的 search_opportunities 枚举逐字一致；`validateEntry` 拦非法值。
3. `WIKI_PIPELINE_CONFIG`：dailyReport owner=`zhanglunet`、slaHours=24、requireHumanConfirm=true；
   conferenceCalendar 168h；d1Snapshot 72h（无需人工确认）。T3（trend #68）直接消费。

## 取舍

- 零依赖 TF-IDF 而非外部 embedding：Wiki 语料小，TF-IDF 够用且可解释；`WikiEmbedder` 接口已预留，
  未来语料增大可替换，search 的过滤/排序逻辑不变。
- 中文分词：bigram + 单字 unigram 兜底（借鉴 contract-prereview T2 的自研 bigram 思路）。
- 生产 D1 只读：本层只消费 `WikiEntry[]`；D1 行 → WikiEntry 的真实映射由 T5（trend #70）实现。
